作品の内容

【デスクトップを自由に動き回る！ウーパールーパー育成ゲーム！】

### 打つほど、育つ。

デスクトップの隅で、ウーパールーパーがゆっくり歩き回ります。

ときどき立ち止まって、こちらを見て、また歩き出す。それだけの小さなソフトです。

ただし、ひとつだけ仕掛けがあります。

**あなたがキーボードを打つほど、この子は大きく育ちます。**

原稿を書いた日も、コードを書いた日も、メールを返しただけの日も、

打った回数はすべて記録され、そのぶんだけ体が大きくなっていきます。

今日の作業が、そのまま育成になります。

### 1,000回で1px、ヌシまで約140,000回

40pxの幼生から始まり、1,000回の入力ごとに1pxずつ成長します。

一定の大きさに達すると姿が変わり、全部で6段階。

| 段階 | 大きさ | 目安 |

|---|---|---|

| 幼生 | 40px | はじまり |

| 幼体 | 55px | 15,000回 |

| 若魚 | 75px | 35,000回 |

| 成体 | 100px | 60,000回 |

| 大成体 | 135px | 95,000回 |

| ヌシ | 180px | 140,000回 |

一日に打つ回数は人によって大きく違いますが、

仕事や勉強でパソコンを使う方なら、数週間から数か月でヌシに届きます。

急いで育てる方法はありません。気長にお付き合いください。

### ときどき、世話をする

時間が経つとおなかが減り、体も汚れていきます。

エサをあげて、お掃除をして、ときどきなでてあげてください。

なつくと、ときどきマウスカーソルのほうへ寄ってきます。

放っておくと弱ってしまいますが、すぐに星になるわけではありません。

弱ってから10分の猶予があります。気づいたときに世話をすれば元気になります。

間に合わなかった場合も、それまでの成長の半分を受け継いだ次の代として

生まれ変わりますので、積み上げたものが全部消えることはありません。

外出中や就寝中に星になってしまわないよう、終了中の時間の進み方には

上限を設けてあります。

### 記録が残る

打った回数は日ごとに記録され、飼育記録の画面でグラフとして振り返れます。

「先週は思ったより打っていたな」と分かるくらいの、ささやかな記録です。

実績も全16種類あります。累計の入力数、育てた大きさ、世話の回数、

深夜の作業量など。ひとつだけ隠し実績があります。

### 数えているのは、回数だけです

このソフトは打鍵数を数えるために、キーボードとマウスの入力を監視しています。

どういう仕組みか、正直にお伝えします。

**記録するもの**

- 入力された「回数」だけ(1日ごとの合計)

**記録しないもの**

- どのキーを押したか

- 入力した文字、パスワード、文章の内容

- 使用中のアプリ名、ウィンドウのタイトル、閲覧しているサイト

- 画面の内容、スクリーンショット

**通信**

- インターネット通信は一切行いません。すべての記録はお使いのパソコンの中だけに保存されます。

この仕組みの性質上、ウイルス対策ソフトが警告を出すことがあります。

悪意のあるソフトも同じ仕組みを使うため、動作の特徴だけで検出されるためです。

### できること

- 左クリックでなでる/ドラッグで移動/右クリックでメニュー

- `Ctrl + M` で隠す・表示(隠している間も回数は数えます)

- `Ctrl + Shift + F` でエサ、`Ctrl + Shift + C` でお掃除

- 通知領域(タスクトレイ)に常駐

- 動きの速さ、夜になる時刻、音の有無などを設定可能

- パソコン起動時の自動起動(設定した場合のみ)

- マルチモニタ対応

なお、成長に必要な入力数やおなかの減る速さは変更できません。

どなたも同じ条件で育てたことになるようにするためです。

### 動作環境

- Windows 10 / 11(64bit)

- 空き容量 100MB 程度

- インターネット接続は不要

macOS / Linux には対応していません。

### ご購入前にご確認ください

- キーボードとマウスの入力を監視するソフトです(内容は記録しません)

- ウイルス対策ソフトが警告を出す場合があります

- 自動起動は、お客様が設定した場合のみ行われます

- 育てた記録はドキュメントフォルダに保存され、他のパソコンへ移せます

本作のグラフィックの一部に、生成AIを使用しております。ウーパールーパーのキャラクターデザインの生成に活用し、生成された画像に対して一部手作業による修正・加工を行っております。
