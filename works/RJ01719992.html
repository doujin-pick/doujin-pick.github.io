【縦書きで書いて、そのまま同人誌の本文 PDF にします】

縦書きの画面で小説を書き、判型(A5 / 文庫 / B6)と段組(1 段 / 2 段)、天・地・ノド・小口の余白、文字の大きさと行送りを決めて「PDF を書き出す」を押すと、同人誌の本文 PDF を書き出します。

右綴じの本として、奇数ページはノドが右、偶数ページはノドが左になります。ノンブル(ページ番号)は地の小口側か中央、柱は作品名か章の見出しを入れられます。

書いた原稿はブラウザの中に自動で保存され、txt と Markdown でも保存できます。

【禁則とルビと約物を、自動で整えます】

行頭に「、」「。」「」」「ー」や小さい「っ」が来ないように、行末に「「」「(」が残らないように、自動で送ります。句読点は行末にぶら下げます(設定で切れます)。

「……」「——」は行をまたぎません。段落の頭は自動で 1 字下げます(「「」で始まる行は下げません)。

「、」「。」「ー」「「」」などの約物は、フォントの縦書き用の字形で出します。英数字は横倒しになります。

ルビは |漢字《かんじ》 と書くと親文字の右に半分の大きさで付き、親文字は行をまたぎません。《《文字》》 で傍点が付きます。

【章とシーン、文字数、日別の執筆量】

「# 見出し」の行が章、「## 見出し」の行がシーンになり、左の一覧に文字数つきで並びます。クリックでその行に移動します。

章は PDF で改ページして始まります。「[newpage]」の行でも改ページできます。「// 」で始まる行は執筆メモで、文字数に数えず PDF にも出ません。

文字数は空白・ルビ・記法を除いて数え、今日どれだけ書いたかを日ごとに 14 日分残します。

【フォントは、お手元のものを選んで埋め込みます】

このソフトにフォントは入っていません。TTF / OTF のフォントファイルを選ぶと、その字を PDF に埋め込みます(使った字だけ)。

おすすめは無料の Noto Serif JP(Google Fonts で入手。zip の中の .ttf を選びます)。IPA 明朝、源ノ明朝、游明朝などの TTF / OTF も使えます。

一度選ぶと、次回からは自動で使います。フォントも原稿も、どこにも送られません。

【選べること】

・判型 … A5(148×210mm)/ 文庫(105×148mm)/ B6(128×182mm)

・段組 … 1 段 / 2 段(段間も指定)

・余白 … 天・地・ノド・小口(mm)

・文字 … 大きさ(pt)と行送り(倍率)

・ノンブル … 地・小口側 / 地・中央 / なし。開始ページの番号

・柱 … 作品名 / 章の見出し / なし

・字下げ、句読点のぶら下げ … 入 / 切

・保存 … txt / Markdown(ルビは <ruby> に変換)。読み込みも同じ形式

【体験版と動作環境、AI の利用、できないこと】

体験版でも、編集・保存・書き出し・フォントの読み込み・組み方の設定は製品版とまったく同じものが動きます。PDF は 3 ページまでで、各ページに「体験版」の透かしが入ります。ご自分の原稿とフォントで組み方を確かめてからお求めください。

HTML ファイル 1 つです。ダブルクリックしてブラウザで開いてください。インストールも会員登録も要りません。Google Chrome で動作を確認しています。

このソフトの画面とコードの作成に AI を利用しています。組版と PDF の生成は、あらかじめ決めた規則に沿って計算しています(AI が文章を作ったり判断したりはしていません)。画像生成 AI は使っていません。

できないこと: 表紙・奥付・目次は作りません(本文のみ)。フォントは 1 種類 1 ウェイトで、太字や斜体の混在はできません。縦中横(2 桁の数字を 1 字に立てる)と塗り足し・トンボは付きません。校正や表記ゆれの点検はしません。書き出した PDF の中身は数えて表示しますが、印刷所で受け付けてもらえるかどうかまでは分かりません(出す先の入稿案内をお確かめください)。OTF(CFF)のフォントでは PDF が数 MB になります(TTF を選ぶと小さくなります)。組み方が設定と違う、禁則が守られていない、といったときは作品ページからサークルへのメッセージでお知らせください。直します。
