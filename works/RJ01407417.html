作品紹介

【キャラメイク特化型エロRPG　作りだした主人公と旅をしよう！】

【ユニゾンコード】の主人公は、あなたが作ったキャラクター。

髪型や胸の大きさ、角や猫耳、陰毛の有無等、様々なパーツから選び、

他の誰とも違う、あなただけの主人公を作りだそう！

可愛らしい主人公でも、凛々しい主人公でも、ダウナーな主人公でも。

清純そうな主人公が露出狂だったり、派手な見た目なのに純潔を大事にしていたり。

あなたの理想が、あなたの性癖が。プレイヤーの想いがきっと叶うキャラメイク！

容姿おまかせボタンで、同じ容姿が出てくることはほとんど存在しないと言える程、様々な種類のパターン！

同じ1枚のCGでも雰囲気が変わりますので、周回したり、気分転換に容姿を変えて回想を楽しんで下さい！

アクセサリーをイベントや街の道具屋を買ってさらにアレンジ。

眼鏡、首輪、アホ毛、乳首ピアス、リボン、淫紋。さらに、一部アクセサリーは色も変わる。

主人公の見た目をどんどんカスタマイズして、理想を叶えましょう！

ボイスパターンは性格別の5種類！

淫乱度によって喘ぎボイスも変わりますので、世界に一人しかいない主人公を作り上げて下さい！

CV:御子柴泉/星野天/篠守ゆきこ/彩夢ひな/藤村莉央

【キャラメイクした主人公がえっちな目に！?】

キャラメイクした容姿は、CGにも反映されます！

戦闘中魔物に拘束されそのまま犯されたり、街を歩いているとセクハラを受けたり。

夜のスラム街を歩いていたら襲われ、怪しい占い師に話しかけたら催○され。

お金の為に自分から身体を売ったり、病人の世話の為に慰めてあげたり。

あなたの主人公が、旅先で色んなえっちな目にあいます。

理想の主人公のエロを楽しむのも良いですし、純潔を守り切る事も出来ます。

胸の大きさや陰毛の有無で反応が変わる事もあります。是非、様々な容姿で楽しんで下さい！

多くのシチュエーションのエロCG。主人公が関わるモノは、全てにキャラメイクが反映されます。

淫乱度で文章や表情が変わったり、主人公の感度で相手の反応も一部変わります。

露出狂になれば、全裸で街をうろつく事も出来ます。

裸マントでセクハラを受ければ、マント下が全裸であることがバレたり、

全裸のまま人に話せば、逃げる人や、性的な目で見てくる人も。

NPCの会話パターンが多く変化します。

他にも主人公の淫乱度によって一部反応が変わったり、表情やボイスが変わったり。

中に出され妊娠した状態でうろつく事ができたり。

あなたの主人公を、あなたの好きなように遊んで下さい！

【三つの戦闘システムは、さくさくプレイも、じっくり考えながらのプレイも！】

【ユニゾンコード】は、三つの戦闘システムを選ぶことが可能です(プレイ中いつでも変更できます)

---------------------------------------------------------------------------------------------

■らくらく戦闘

1ボタンで勝利や敗北、戦闘中に襲われた時、挑発や自慰などのCGが閲覧できます。

「ストーリーだけ見たい」「エロだけ見たい」「経験値稼ぎをしたい」など、

気軽にサクっと遊べるシステムです。

■ふつう戦闘

特に難しいシステムは無しで、敵との戦闘を楽しめます。

強いスキルで攻撃し、相手からの攻撃を受けては回復し、自己強化スキルを使って大技を決める。

レベリングや戦闘を楽しみながら遊べるシステムです。

■じっくり戦闘

【ユニゾンコード】オリジナルの、少し変わった戦闘です。

相手と自分の速度・命中の数値を見ながら、じっくり考えて戦闘を優位に進めます。

少し慣れは必要ですが、理解すれば骨太な戦闘を楽しめるシステムです。

---------------------------------------------------------------------------------------------

他にも、戦闘で得たスキルポイントを使って、主人公はアビリティを取得できます。

攻撃力を上昇させたり、生存重視のアビリティを覚えたり、中には「処女なら発動する」「妊娠中なら発動する」アビリティも。

戦略を組み立て、自分の主人公ならではの戦い方を楽しみましょう！

【様々な悩みを抱えるヒロインを救おう！　敗北すれば・・・】

主人公は旅の道中、様々なヒロイン達と出会います。

彼女達は主人公と出会い、運命が変わります。

ヒロイン達は全員にボイスがついており、シーンによってはボイス付きでストーリーが楽しめます！

ヒロイン達との冒険は、最後に大きな戦闘が行われます。

そこに敗北すれば、主人公とヒロインは・・・

CV:砂糖しお / 成町茎 / 道楽みぃ / まあ油るる / 竹早芽衣 / 暁鞠子 / 眠音りま / 夢月やみ / 神代そら / かの仔 / 雲雀ゆい / 星月るな / ゆきかすみ / 碧葉 ルナ / 佐京柚音

【さまざまなシステム】

■エロステータス

えっちな目に合う度に、エロステータスが上昇します。

エロステータスが上昇すれば乳首色や噴乳の設定が解放され、CGに反映されます。

■娼館

主人公は娼館で働くことが出来ます。

身体の開発が進めば口・胸・膣・尻・その他から様々なプレイで客と性交出来ます。

■キャンプ

旅の途中、キャンプをすることが出来ます。

身体を休めたり、服を修繕したり、誰も居ない場所で身体の開発を進める事が出来ます。

■設定変更

紹介した他にも、様々な遊び方が存在します。

ダメージや獲得金額、淫乱度上昇の倍率を変更することも可能です。

CG・回想・アクセサリーなどの収集要素は全開放出来るボタンがあります

【ストーリー】

主人公は田舎に住む少女。

幼馴染と共に日課の狩りで競い合っていると、森に轟音が鳴り響く。

この世界の伝承。『轟音と共にダンジョンが現れ、異世界へと繋がる』

おとぎ話のような出来事が、主人公の村の近くで起きたのだ。

ダンジョンへと入り、見た事も無い魔物を倒しながら奥へと進む主人公。

そこで、彼女は出会う。

小さな指輪から映し出される、小さな姿の女の子。

主人公を可愛らしく見つめた彼女は、とても元気に語りだす。

『お気軽にUDちゃんとお呼びください、臨時マスター！』

『さぁ、世界と未来を、救いましょう！』

小さな相棒と旅するキャラメイク特化型RPG

あなたが作った主人公で旅をしよう！
