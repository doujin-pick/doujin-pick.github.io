作品の内容

【複数キャラの関係を、矛盾なくまとめて作ります】

人数と関係(親子・兄弟姉妹・夫婦・幼馴染・上司部下・師弟・宿敵・恋人)を決めて「生成する」を押すと、全員の名前・年齢・身長・体格・職業・性格・口癖・出身をまとめて作ります。

親子は年齢差 16〜45 で同じ姓、兄弟姉妹は同じ姓と同じ出身、幼馴染は同じ出身で年齢差 3 以内、上司は部下より年上で同じ職種——といった整合ルールを、全員同時に満たす形で決めます。

祖父・父・子のように関係が鎖になっても、家族と職場がつながっていても、矛盾しません。

【生成のたびに、全員をルールで検査します】

生成した結果は、関係ごとの整合ルール(年齢差・最低年齢・姓・出身・職種)に照らして毎回検査し、「整合の検査: 違反 0」と画面に出します。

両立しない指定(たとえば同じ 2 人を親子と恋人にする)は、生成の前に「どの関係を外せば解けるか」を添えて止めます。

整合ルールの一覧は画面の中で読めます。

【相関図と、CSV / Markdown で持ち出せます】

生成した人物と関係を相関図(SVG)にします。関係ごとに色と札が付き、親→子・上司→部下・師→弟子は矢印で向きが分かります。

一覧は CSV(表計算ソフトでそのまま開けます)と Markdown(表 + 関係の一覧 + 各人の詳細)で保存できます。相関図の SVG はブラウザや画像編集ソフトで開けます。

【気に入った人だけ残して、作り直せます】

気に入った人に「固定」のチェックを入れ、「固定していない人だけ作り直す」を押すと、固定した人はそのままに、残りをルールに合うように作り直します。

シードの欄に同じ文字列を入れると、同じ設定で同じ結果になります。JSON で保存しておけば、あとで読み込んで続きから作り直せます。

【選べること】

・名前の系統 … 和名(姓 200・名 200)/ 洋名(姓 100・名 120)/ ファンタジー(家名 100・名 120)。すべてこの作品のために作った辞書です

・人数 … 1〜30 人

・関係 … 親子 / 兄弟姉妹 / 夫婦 / 幼馴染 / 上司部下 / 師弟 / 宿敵 / 恋人。何本でも指定できます

・職業 … 現代(学校・会社・医療・警察・飲食・芸能・スポーツ・職人・出版・研究・自営 ほか)とファンタジー(騎士団・魔術師・冒険者・商人・神殿・王宮・職人・農村・海 ほか)。年齢に合うものから選びます

・書き出し … CSV / Markdown / 相関図 SVG / JSON

【体験版と動作環境、AI の利用、できないこと】

体験版でも、生成と整合の検査は製品版とまったく同じものが動きます。人数は 4 人まで、書き出しはできません。ご自分の使い方に合うかを確かめてからお求めください。

HTML ファイル 1 つです。ダブルクリックしてブラウザで開いてください。インストールも会員登録も要りません。入力した内容はどこにも送られません。Google Chrome で動作を確認しています。

このソフトの画面とコードの作成に AI を利用しています。生成と検査は、あらかじめ決めた規則に沿って計算しています(AI が文章や絵を作ったり判断したりはしていません)。名前・職業・性格・口癖の辞書は人が書いたものです。画像生成 AI は使っていません。

できないこと: 画像(似顔絵・立ち絵)は作りません。年齢は 6〜70 歳の範囲です。関係の自由記述(「元同僚」など)はできません。相関図の配置は自動で、画面上で動かすことはできません(SVG を保存して外で編集できます)。ルール違反の結果が出た・生成できない組み合わせがある、といったときは作品ページからサークルへのメッセージでお知らせください。直します。
