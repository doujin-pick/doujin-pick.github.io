【ストーリーとポイント】

近未来、人間が変貌した怪物【アノマリー】と戦う戦隊組織”CAF”。

その一員であるサイファーピンクは、隊員の義務である戦闘後の報告を上官

である司令(あなた)に行っていた。

ピンチに陥った場面を詳しく報告するうち、司令がその内容に興奮していることに気づいたピンクは、慰労と称して「NTR報告プレイ」を始めていき――。

◆　「チン嗅ぎ」「顔舐め」「触手」など、ニオイに関する表現を多数収録

◆　怪物に寝取られるという新感覚NTR報告

◆　報告を聞かされる側にも、責められる女性側にも感情移入が可能

◆　「サイズ比較」「罵倒」「見下し」要素は少なめ、もしくは無し

【メインキャラクター】

サイファーピンク/浅霧メイカ

CV.涼貴涼

CAF《Counter ANOMALY Force》に所属する若手メンバー。経験は浅いが実力は折り紙付きで、周囲からの信頼も厚い。上官である司令とは恋仲にあり、密かに逢瀬を重ねている。

やや潔癖症であり、汚いものや臭いニオイが苦手。自身も綺麗好きで、司令と会うときは必ずシャワーを浴びるようにし、また司令にもそれを強要する。

???/風見カエデ

CV.鬼霧茜

アノマリー研究の第一人者であり、かつてCAFメディカルセンターのセンター長だった人物。3年ほど前に突如失踪、以後行方不明となっていたが…。

司令(あなた)

的確な作戦でCAFを勝利に導く司令官。隊員からの戦闘報告を作戦に役立てているが、アノマリーに敗北したときの描写を細かくヒアリングする悪癖があり、やがてそれはCAFの未来を左右することとなる。

戦闘後の報告業務を行うサイファーピンク。報告完了後、いつものように2人は司令の部屋で密会を約束する。

02　ブリーフィング1　(1:45)

アノマリーが出現したとの緊急信号を受け、サイファーピンクは司令から簡単な情報共有を受ける。カテゴリーは人型で、危険度は比較的低い。彼女はモニターに映る、触手を生やしたアノマリーに嫌悪感を覚えながらも、ただちに現場である7番市街地に急行するのであった。

--

03　人型アノマリー戦闘報告1　(35:51)

【触手拘束 / 乳嬲り / 触手顔面陵○ / 唇コキ / イラマチオ / 口内射精】

憔悴した様子でCAF本部に帰還したサイファーピンクは、アノマリーとの戦闘に敗北したことを司令に告げる。敗北したとはいえ、戦闘報告はCAFの義務。敵に陵○される様を事細かに報告するうち、それを聞く司令の様子がおかしいことに気づき…。

--

04　ブリーフィング2　(1:44)

緊急招集を受け、次のターゲットの情報を確認するサイファーピンク。蜂のようなフォルムに変異した女性型のアノマリーが、6番市街の物流倉庫に現れたという。作業員がまだ取り残されているという情報もあり、一刻を争うと判断した彼女は単身で現場に向かった。

--

05　人型アノマリー戦闘報告2　(29:49)

【貝合わせ / ディープキス / エナジードレイン / オホ声 / 顔面騎乗】

またもや敵に敗北し、救援されたサイファーピンクは隊員の義務を果たすべく司令室へ向かう。前回、二度としないと決めたものの、司令への慰労と称して再び耳元で寝取られ報告をしてしまうのであった。彼女自身も徐々にその行為に悦びを覚えるようになり…。

--

06　ブリーフィング3　(2:16)

融合型カテゴリーという、最も危険度の高いアノマリーの情報を耳にする。近々、大規模な掃討作戦が予定されているということも。その時、CAF本部にアラートが鳴り響く。人型よりも厄介な変異型のアノマリーが出現したとのことで、サイファーピンクとサイファーブルーの共同任務が始まった。

--

07　変異型アノマリー戦闘報告　(31:03)

【臭気ガス / オホ声 / 顔舐め / 丸呑み / 触手陵○ / 膣内射精】

共同任務にもかかわらず、ワームのようなフォルムをした強大なアノマリーの前に敗北を喫してしまう。戦闘経験豊富なブルーも、あっという間に丸呑みにされてしまったようだ。サイファーピンクは率先して司令の耳元に近づき、その時の状況を再現しながら手淫に興じる。彼女自身、敗北マゾに目覚めてしまったことを自覚しながら…。

--

08　ブリーフィング4　(5:58)

融合型アノマリー掃討作戦の日が近づいていた。メンバー総動員での作戦であることから、当日の動きを細かくチェックするサイファーピンク。メンタルトレーニングを経て、精神が安定した彼女はもう大丈夫と司令を安心させる。一方、ターゲットに関する意外な情報を知らされ、彼女は困惑しつつも責務を果たそうと決意するのであった。

09　廃工場に残された記録　(22:23)

【エロ妄想汚染(口臭 / 心情代弁 / オホ声 / 鼻舐め / チン嗅ぎ / 顔コキ)】

これは、サイファーピンク目線の作戦当日の記録である。チーム壊滅後、最後に残された彼女が融合型アノマリーに必死に抵抗する様子が生々しく記録されている。アノマリーは彼女のヘルメットを解除させるべく、エロ妄想を囁くことで敗北マゾを再発させようとしていたのだ。
