【SVG ソース・スプライトシート・Godot 用 JSON つきの魔法陣エフェクト連番】

SVG ソース+スプライトシート+Godot 用フレーム JSON つきの、図形だけで描いた魔法陣エフェクトの連番素材です。

12 種の魔法陣を、回転・点滅・展開の 3 つの動きで連番にしました。色は 4 種、サイズは 512px と 256px の透過 PNG。

画像を並べるだけでなく、SVG の色や寸法を変えて作り直せます。

■ 同梱物

・魔法陣 12 種 × 動き 3 種 × 色 4 種 × サイズ 2 種 = 288 連番

回転 24 コマ/点滅 16 コマ/展開 20 コマ(回転と点滅は継ぎ目のないループ)

色:青・橙・赤・紫

・個別 PNG(透過)5,760 枚

・スプライトシート 288 枚+フレーム JSON 288 本(各コマの x, y, w, h と fps つき)

・SVG ソース 720 枚(色・寸法の編集用。青の色のみ)

・Godot 4 で JSON から SpriteFrames を作る小さなスクリプト

・使い方(README.txt)、魔法陣の一覧と色コード(DESIGN.txt)、利用条件(LICENSE.txt)

■ 魔法陣の例

六芒星・五芒星・八芒星・七芒星・九芒星の陣、花弁の陣、歯車と軌道の陣、光条の輪、重なる円の格子、分割円弧、入れ子の方陣など 12 種。

■ 使い方(Godot 4)

同梱のスクリプトで、JSON から SpriteFrames を作って AnimatedSprite2D で再生できます。手順は README.txt に書いています。

JSON は x, y, w, h だけの汎用の形です。他のエンジンの切り出し設定へ読み替えて使えます。

色を変えたいときは SVG の色コードを置換して、Inkscape などで PNG に書き出してください。

■ 動作確認について

・コマ数・寸法、個別 PNG とシートの一致、ループのつなぎ目を画素比較で確認しています。

・Godot 4.x(4.7.2)で、同梱の JSON と PNG から SpriteFrames を作り、AnimatedSprite2D で再生できることを確認しています。
