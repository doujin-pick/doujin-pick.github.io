■01　シーン1　ゆかりママ&ちひろママのレズセックス

( 正常位レズセックス / オホ声 / ベロチュー / 尻尾ペニス / 中出し / 寝取られ風プレイ / ポルチオ責め / 耳舐め / 耳元囁き / 「好き好き」言い合い / 大ちゅきホールド)

ちひろママが提案した今回のトレーニング方法は、

『ゆかりママが勇者バブちゃんの味方である僧侶になって、サキュバス魔王様となったちひろママと戦う、RPGゲーム風のセックスバトル』。

ちひろママはゆかりママに覆い被さり、媚薬エキス射精機能が付いた尻尾ペニスで激しく犯し始めます。

元々マゾ気質だったゆかりママは、普段からは想像できないような獣のようなオホ声を上げて感じまくり、

メスマゾちゃん大好きなちひろママも、興奮でピストンの勢いが止まらなくなって、本気ラブラブ恋人交尾で昇り詰めていきます。

その途中ゆかりママに「勇者バブちゃんのことは忘れて、私と恋人眷属になりましょう?」と悪魔の囁きをします。

シリーズ内の時系列としては、【かなでママ編】のプロローグ直後のシーンとなります。

■02　シーン2　しおりママ&かなでママのレズセックス

( 正常位レズセックス / オホ声 / ベロチュー / ペニスバンド / お尻ペンペン / SMプレイ / 耳元囁き / 「好き好き」言い合い / 言葉責め / 大ちゅきホールド)

かなでママが、しおりママに激しい躾セックスをいやらしく誘惑し、

それに乗せられたしおりママが極長ペニスバンドを装着して、本気のお尻ペンペンお仕置きセックスを始めます。

お尻を叩かれるたびに、かなでママのおマンコがキツく締まり、二人とも激しく感じてしまいます。

そのまましおりママはペニスバンドでの攻め方を、かなでママはラブラブ魅了方法をお互いに教え合いながら、

動物のようなドスケベ声を上げて一緒に絶頂へと昇り詰めていきます。

シリーズ内の時系列としては、【ちひろママ編】のプロローグ直後のシーンとなります。
